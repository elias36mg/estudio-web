# 📚 Estudio Web

Una plataforma moderna de aprendizaje en línea con una interfaz intuitiva y recursos educativos interactivos.

## ✨ Características

- 🎨 Diseño moderno y responsivo
- 📱 Compatible con dispositivos móviles
- 🎓 Múltiples categorías de cursos
- ⚡ Animaciones suaves y fluidas
- 📦 Fácil de personalizar

## 🚀 Cursos Disponibles

1. **Programación** - Python, JavaScript y más
2. **Matemáticas** - Álgebra, cálculo y estadística
3. **Idiomas** - Inglés, español y otros
4. **Diseño** - UI/UX y gráficos

## 📂 Estructura del Proyecto

```
estudio-web/
├── index.html      # Página principal
├── styles.css      # Estilos del sitio
├── script.js       # Funcionalidad interactiva
└── README.md       # Este archivo
```

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones y gradientes)
- JavaScript vanilla

## 📝 Cómo Usar

1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. ¡Explora los cursos y recursos!
